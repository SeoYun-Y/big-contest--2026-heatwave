# 같은 날씨, 다른 피해: 폭염과 폭우에 따른 강남·춘천 상권의 기후 취약성 분석

2026 빅콘테스트 AI데이터 분석 분야 **「기후 위기에 따른 취약 상권 영향 분석」** 참가 코드입니다.

> **데이터 안내**: 대회 제공 데이터(신한카드, SK 유동인구)와 이를 가공한 파일은 대회 규정에 따라 이 저장소에 포함하지 않습니다. 실행하려면 `data/README.md`에 적힌 위치에 데이터를 넣어야 합니다.

## 대시보드

`17_dashboard`를 실행하면 `outputs/dashboard/dashboard.html`이 만들어집니다. 인터넷 없이 브라우저에서 열립니다.

- **관광객 화면**: 예보 강수량 → 혜택 신호등(10mm 1단계, 30mm 2단계) → 혜택·제휴처 후보·비 오는 날 코스
- **시청 화면**: 예보 → 취약 격자 지도, 우선 지원 행정동, 강남 vs 춘천 비교

시청 화면에는 대회 데이터로 만든 격자 값이 들어가므로 외부에 공개하지 않습니다.

## 데이터 취급

- 포함하지 않음: 대회 제공 데이터(신한카드, SK 유동인구)와 이를 가공한 데이터.
  대회 규정에 따라 대회 종료 후 삭제합니다.
- 포함함: 팀이 직접 수집한 공개 외부 데이터(기상청 ASOS, 행정동 경계,
  골프장·레고랜드 좌표)와 팀이 만든 업종 분류표.
- 용량 때문에 제외: 상가(상권)정보 원본은 공공데이터포털에서 내려받습니다.
- 노트북은 대회 데이터 미리보기가 남지 않도록 출력을 지운 상태로 올립니다.
